# DESIGN.md — UI/UX & Design Taste System

## 1. Visual Theme & Direction
- **Aesthetic Direction:** Clean High-End Studio & Editorial Platform
- **Form Factor Focus:** Mobile Apps & High-End Web Interface

## 2. Color Palette & Design Tokens
- **Canvas Ground (Background):** `#fafafa`
- **Surface / Cards:** `#ffffff` (Elevated with soft ambient shadow `rgba(0,0,0,0.03)`)
- **Border Hierarchy:** `#e2e8f0` (1px clean border separation)
- **Primary Brand Accent:** `#4f46e5`
- **Secondary Accent:** `#06b6d4`
- **Headings & Primary Text:** `#0f172a`
- **Body Text:** `#334155` (Readable line-height 1.75)

## 3. Typography Hierarchy
- **Primary Typography:** Plus Jakarta Sans (Weights: 400, 500, 600, 700, 800)
- **Monospace Typography:** JetBrains Mono for code, JSON, math expressions, and metrics.

## 4. Active Anti-Slop Interface Laws
- [x] **Zero generic AI icons (No sparkles / stars)**
- [x] **Mobile-first responsive reflow (Safe-area insets & zero horizontal scroll)**
- [x] **No card-in-card unnecessary nesting**
- [x] **Explicit touch targets (minimum 44x44px tap target size for mobile)**
- [x] **WCAG 2.2 AAA Contrast compliance**
